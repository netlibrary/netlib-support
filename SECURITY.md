# Security Policy

**Please do not report security vulnerabilities as public issues.**

Use GitHub's private vulnerability reporting for this repository:
https://github.com/netlibrary/pinbase-support/security/advisories/new

Only you and the Pinbase maintainers can see the report. If you cannot use
GitHub, send an e-mail to **support@pinbase.app** with the subject "Security".

We will confirm receipt within a few days, keep you informed about the fix and
credit you if you wish. Please give us reasonable time to close the issue
before making it public.

---

# Sicherheitshinweise

**Bitte melde Sicherheitslücken nicht als öffentliches Issue.**

Nutze die private Meldung von GitHub für dieses Repository:
https://github.com/netlibrary/pinbase-support/security/advisories/new

Die Meldung sehen nur du und die Pinbase-Betreiber. Wenn du GitHub nicht
nutzen kannst, schreibe an **support@pinbase.app** mit dem Betreff
„Sicherheit".

Wir bestätigen den Eingang innerhalb weniger Tage, halten dich über die
Behebung auf dem Laufenden und nennen dich auf Wunsch. Bitte gib uns
angemessen Zeit, die Lücke zu schließen, bevor du sie veröffentlichst.
